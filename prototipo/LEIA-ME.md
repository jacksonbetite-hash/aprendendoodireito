# Protótipo estático (histórico)

Estas telas foram o primeiro passo: validaram fluxo e identidade visual antes
de escrever o código de produto. **Não são mais o sistema** — a aplicação real
está em `app/` (Next.js) e lê tudo do PostgreSQL.

Ficam aqui como referência de design. O `css/styles.css` daqui foi promovido a
`app/globals.css` e é o design system em uso.

Para abrir: `cd prototipo && python -m http.server 8080`.
